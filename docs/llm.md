# Какая LLM

Подойдёт любая — мастер `hh-agent setup` спросит и проверит её тестовым запросом
(запустите его ещё раз, чтобы сменить LLM):

| `analyst.backend` | Что это | Что нужно |
|---|---|---|
| `codex` | Codex CLI по подписке ChatGPT (по умолчанию) | `codex login` |
| `claude_code` | Claude Code CLI по подписке claude.ai | установленный `claude` |
| `api` | Claude API | `ANTHROPIC_API_KEY` |
| `openai` | любой OpenAI-совместимый API: OpenAI, OpenRouter, DeepSeek, Gemini, Mistral, Groq, локальные Ollama, LM Studio, vLLM | `base_url`, `model`, ключ в `api_key_env` |
| `command` | любая программа: запрос в stdin, JSON-ответ в stdout (например, `ollama run qwen3`) | `command` |

Ответы LLM всегда по JSON-схеме: для `openai` агент просит строгую схему, а если сервер её
не поддерживает — `json_object` или схему в тексте запроса, и проверяет ответ. Ключ API мастер
сохраняет в `.env` рядом с `config.yaml` (в git не попадает): так его видит и запуск по
расписанию, которому недоступны переменные из `~/.zshrc`.

`analyst.letter_backend` — бэкенд для писем: `same` — письмо в том же запросе, что и оценка;
имя бэкенда — отдельным запросом и только для вакансий с проходным баллом (дешевле).
Для Codex модель и глубину рассуждения задают `analyst.codex_model` (например, `gpt-6-astra` —
самая сильная) и `analyst.codex_effort` (`low` … `max`); без них Codex берёт значения по умолчанию.

`analyst.fallback_backend` — запасной бэкенд на случай, когда у основного кончились лимиты,
например `claude_code` за Codex; мастер `setup` спрашивает его сразу после основного. Свои
`model`, `base_url`, `api_key_env` и другие поля для него — в `analyst.fallback_settings`
(без них берутся общие из `analyst`). Агент
сразу повторяет запрос через запасной и работает только с ним до времени сброса лимита из
ответа (у Codex — «try again at 4:37 PM»), в том числе в следующих запусках (`.llm-limits.json`);
после этого возвращается к основному. Если время в ответе не указано — до конца запуска. Переключение видно в консоли и в журнале (событие `llm_fallback`).

## Сколько это стоит

Ориентир — по журналу автора (46 откликов, `hh-agent stats`):

| Что | Токенов на отклик |
|---|---|
| поиск, оценка, письмо, анкета работодателя | ~13 тыс. |
| плюс опрос AI-рекрутера в Telegram (Сбер) | ещё ~25 тыс. |
| **всего** | **~38 тыс.** |

- **По подписке** (Codex, Claude Code) отдельно не платите, но упираетесь в лимит. На подписке
  ChatGPT ниже Pro лимит Codex у автора кончился примерно на 1,5 млн токенов за день — это около
  20 откликов с опросами Гигарекрутера. Дальше агент переходит на запасную LLM (`fallback_backend`)
  или ждёт сброса лимита.
- **По API** платите за токены. Для Claude Opus у автора выходило около $6–7 за 1 млн токенов
  (с учётом кеша), то есть примерно $0.25 за отклик с опросом в Telegram и $0.09 без него.
  Цены меняются — сверяйтесь с прайсом провайдера.
- **Локальная модель** (Ollama, LM Studio) — бесплатно; качество оценки и писем зависит от модели,
  и чем она сильнее, тем больше ей нужно памяти.

Расход по дням, назначению и моделям, а для API и Claude Code — и стоимость, показывает
`uv run hh-agent stats`.

У Codex есть обязательная обвязка ~12 тыс. токенов на каждый вызов, поэтому вакансии
оцениваются пачками (`analyst.batch_size`, по умолчанию 8), письма тоже (`letter_batch_size`, 4),
а ненужные инструменты Codex отключены.
