# Поиск и оценка

- Фильтры проще всего настроить на сайте и вставить URL поиска в `searches[].url`.
- Повторный `scan` не открывает и не оценивает уже известные вакансии. Если выдача отсортирована
  по дате (`order_by: publication_time` на hh, `sort: date` на Хабре), поиск заканчивается
  на первой странице, где нет ни одной новой вакансии.
- Если выдача показывает, что вы уже откликнулись на известную вакансию (откликнулись сами на сайте,
  неподтверждённый отклик всё же ушёл), её статус в базе меняется на `applied` — из `new`, `scored`,
  `skipped`, `manual`, `error` и `unconfirmed`. Датой отклика считается момент, когда агент это узнал,
  и отклик идёт в дневной лимит (у `unconfirmed` дата отправки уже есть и остаётся). То же — когда агент
  открывает вакансию для отклика и видит «отклик уже был». Отдельных заходов на сайт для этого нет.
- Вакансия попадает в базу один раз. Чтобы переоценить её после правки резюме:
  `sqlite3 hh_agent.db "update vacancies set status='new' where status='scored'"` и `hh-agent analyze`.
