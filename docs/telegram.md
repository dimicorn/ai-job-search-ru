# AI-рекрутеры в Telegram

Некоторые работодатели (например, Сбер) после отклика проводят опрос через бота в Telegram.
Во время `auto` и `autopilot` (в отдельном потоке, параллельно с откликами) агент проходит опрос
от вашего аккаунта: отвечает текстом или кнопками по резюме, вакансии и `questions.facts`.

Боты перечислены в `telegram.bots` (по умолчанию ГигаРекрутер Сбера, `giga_recruiter_bot`):
отклики с hh он подтягивает сам, поэтому hh.ru агент для этого не открывает. Если бот
незнакомый, можно включить `telegram.hh_links: true` — тогда агент, пока не знает ни одного бота,
ищет ссылку `t.me/<бот>?start=…` в чатах откликов на hh и запускает бота по ней, если чата ещё нет.

У ГигаРекрутера Сбера один чат на все вакансии: после каждого отклика он присылает список
«по какой вакансии продолжить». Вакансию выбирает агент — первую сверху (самую свежую), по которой
опроса ещё не было, при необходимости листая «Далее». После опроса он командой бота «сменить
вакансию» (`/change_vacancy`) берёт следующую, пока есть отклики за `telegram.check_days` без опроса.
Если диалог не идёт (опрос закончен, бот не поздоровался или давно молчит), агент один раз за запуск
сам отправляет `/change_vacancy`; ответ «других вакансий нет» — конец работы с ботом, и следующие
6 часов агент его не переспрашивает. После трёх `/change_vacancy` подряд без результата (бот не дал
выбрать вакансию и ничего не спросил) агент заканчивает работу с ботом.

Настройка: получите `api_id` и `api_hash` на my.telegram.org (API development tools), впишите их
в раздел `telegram` и выполните `uv run hh-agent login`: агент спросит номер, код из Telegram
и пароль 2FA. Сессия хранится в файле `.telegram.session`, как профиль браузера.

```bash
uv run hh-agent recruiters --dry-run   # показать, что агент ответил бы, ничего не отправляя
uv run hh-agent recruiters             # пройти опросы сейчас
```

Если нужен факт, которого нет, нужно выбрать время встречи, перейти по ссылке, записать
голосовое или поделиться номером (`share_contact: false`), агент останавливается, присылает
уведомление macOS и пишет вопрос в `logs/questions.md`. Ответьте боту сами в Telegram,
со следующего запуска агент продолжит. Открытые агентом чаты на hh становятся прочитанными.
