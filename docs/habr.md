# Хабр Карьера

Поиск с `source: habr` (или с `url` на career.habr.com) идёт по Хабр Карьере, остальные — по hh.
Параметры те же, что в адресе страницы `career.habr.com/vacancies`: `q`, `s[]` (специализации),
`qid` (уровень, одно значение), `remote`, `locations[]`, `salary`, `with_salary`, `sort`. Пример есть
в `config.example.yaml`. Выдача читается через JSON API сайта (25 вакансий на странице), описание берётся
со страницы вакансии. Фильтры, оценка, письма, лимиты и `review`/`auto` общие для обоих сайтов.
В `list` есть колонка «сайт».

- `hh-agent login` по очереди откроет вход на каждый сайт из `searches`. На Хабр Карьеру
  входят через Хабр Аккаунт.
- На Хабре отклик уходит **сразу** по кнопке «Откликнуться». Письмо агент дописывает следом
  в форме «Дополнить отклик». Поэтому `auto --dry-run` на Хабре ничего не нажимает, только делает скриншот.
  При `submit_mode: manual` «Откликнуться» и «Дополнить отклик» нажимаете вы, агент только вписывает письмо.
- Если вакансия принимает отклики на сайте компании, она уходит в `manual`. В `review` агент откроет
  этот сайт и скопирует письмо в буфер обмена.
- Если нет входа на один из сайтов, `review` и `auto` пропускают его вакансии и работают с остальными.
- Нераспознанные формы Хабра сохраняются в `debug/habr/`.
