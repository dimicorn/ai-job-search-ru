# hh-agent: агент откликов на hh.ru и Хабр Карьере

С 15.12.2025 hh.ru закрыл API для соискателей, поэтому агент работает через ваш браузер
(Playwright с отдельным профилем, где хранится сессия hh.ru). Откликаться можно
с подтверждением каждого отклика (`review`) или автоматически (`auto`). Кроме hh, агент ищет и откликается на
[Хабр Карьере](https://career.habr.com/vacancies).

> [!WARNING]
> **Используете на свой риск.**
> - Автоматизация браузера противоречит правилам hh.ru: аккаунт могут ограничить или заблокировать.
>   Паузы, рабочие часы и лимиты снижают риск, но не убирают его; в `auto` он выше, чем в `review`.
> - Опросы AI-рекрутеров в Telegram агент проходит от **вашего личного аккаунта** через Telegram API.
>   Telegram может ограничить аккаунт за автоматизацию. По умолчанию эта часть выключена.
> - Письма и ответы работодателям пишет LLM от вашего имени. Агент опирается на резюме и
>   `questions.facts`, но может ошибиться — начните с `review` или `auto --dry-run`.
> - Резюме, вакансии и переписка с ботами уходят выбранной LLM — облачной, если не выбрана локальная.

```
 Разведчик (scout)    →  Аналитик (LLM)            →  Вы (review)        →  Исполнитель (applier)
 выдача hh по          оценка 0–100, причины,        [y] / правка /          заполняет форму,
 фильтрам + локальные   red flags, письмо              переписать / skip       жмёт «Отправить»
 стоп-слова
```

## Установка

Нужно:

- **macOS** — основная платформа. **Linux** — работает, но без уведомлений, `caffeinate`
  и launchd (расписание — через cron). **Windows** — только через [WSL](https://learn.microsoft.com/windows/wsl/).
- LLM: подписка ChatGPT (Codex) или claude.ai (Claude Code), ключ API или локальная модель —
  см. [Какая LLM](docs/llm.md), там же сколько это стоит.
- Python, браузер для агента и остальное `setup.sh` поставит сам.

```bash
git clone https://github.com/dimicorn/job_search_agent.git hh-agent && cd hh-agent
./setup.sh
```

`setup.sh` проводит по шагам: ставит [uv](https://docs.astral.sh/uv/) (если его нет), зависимости
и Chromium для Playwright, запускает мастер `hh-agent setup` (создаст `config.yaml`, `resume.md`,
`faq.yaml`, спросит основную и запасную LLM и частые факты для анкет — зарплату, город, срок выхода),
предлагает войти на hh.ru, Хабр Карьеру и в Telegram, скачать резюме с hh.ru в `resume.md` и включить
ежедневный autopilot. Повторный запуск безопасен: готовое он не трогает. В конце проверьте всё
командой `uv run hh-agent doctor`.

Вручную то же самое: `uv sync && uv run playwright install chromium && uv run hh-agent setup`,
затем `uv run hh-agent login`. При первом запуске любой команды без `config.yaml` мастер откроется сам.

## Использование

```bash
uv run hh-agent help       # список всех команд и их опций (или просто uv run hh-agent)
uv run hh-agent doctor     # проверить, всё ли готово, и подсказать, как починить (--online — ещё вход и LLM)
uv run hh-agent login      # один раз: войти в hh.ru (и Хабр Карьеру, если она есть в searches)
uv run hh-agent resume     # скачать резюме с hh.ru в resume.md (без ФИО и контактов)
uv run hh-agent scan       # найти вакансии и оценить их
uv run hh-agent letters    # переписать письма для оценённых вакансий
uv run hh-agent review     # пройтись по подходящим и откликнуться
uv run hh-agent run        # scan + review
uv run hh-agent stats      # сводка за сегодня, 7 и 30 дней и текущая очередь
uv run hh-agent list manual   # что требует ручного отклика (тесты, анкеты)
```

Кнопки в review: `y` — откликнуться, `e` — править письмо в `$EDITOR`, `r` — переписать
с указанием («короче», «упомяни проект X»), `o` — открыть вакансию в браузере,
`s` — пропустить навсегда, `l` — отложить, `q` — выйти.

## Что важно знать

- `login`, `review` и `run` интерактивные: запускайте их в обычном терминале.
- Если форма не распознана или на вопрос работодателя не хватает фактов, в `review` агент копирует
  письмо в буфер обмена и передаёт управление вам, а в `auto` откладывает вакансию в `manual`.
- `submit_mode: manual` — агент только заполняет форму, а «Отправить» вы нажимаете сами.
- Профиль браузера нельзя открыть в двух процессах: второй запуск ждёт, пока первый закончит.
- Пока идёт `scan`, `auto`, `autopilot` или `review`, Mac не засыпает от бездействия (`caffeinate`).
  Закрытая крышка ноутбука всё равно усыпляет Mac — агент замрёт и продолжит после пробуждения.
- Ctrl+C останавливает агента аккуратно, с итогом запуска; второй Ctrl+C — сразу
  ([подробнее](docs/auto.md#остановка)).
